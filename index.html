Quiz file format 
{
  "title": "My Quiz",                 // optional
  "description": "Short intro text",  // optional
  "questions": [
    {
      "question": "What is 2 + 2?",
      "options": ["3", "4", "5"],
      "answer": 1,                    // index (0 = first) or option text, e.g. "4"
      "explanation": "2 + 2 = 4"      // optional, shown after answering
    }
  ]
}
  • Each question needs at least 2 options.
  • answer is either the option's position starting at 0, or the exact option text.
  • Comments (//) above are for explanation only — real JSON files can't contain them.
